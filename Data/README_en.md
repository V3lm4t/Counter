# Counter

A simple console application written in **C#** that counts sequentially from **1** to a user-specified number and sends the output to the selected OS window.

## 📋 Features

- **Select Target Window** - Select the active window from the list of running processes to send values to.
- **Set Range** - Count from `1` to any specified final number.
- **Process Control** - Simple and intuitive start and stop functions.
- **Customizable support** - Select the interval (in milliseconds) between sending numbers.

## 🛠️ Requirements

- **OS:** Windows 10 / 11
- **Platform:** .NET 10.0
- **Development Environment:** Visual Studio 2026

## 📖 How to Use

1. Compile and run the program. Immediately upon opening, you will be presented with a list of running processes; select the numerical identifier of the desired window.
2. Specify the maximum number and the delay (again, in milliseconds).
3. Use `ESC` to switch operating modes.
