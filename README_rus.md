# Counter

Простое консольное приложение на **C#**, которое выполняет последовательный подсчет от **1** до заданного пользователем числа и отправляет ввод в выбранное окно ОС.

## 📋 Возможности

- **Выбор целевого окна** - указание активного окна из списка запущенных процессов для отправки значений.
- **Настройка диапазона** - подсчет от `1` до любого указанного конечного числа.
- **Контроль процесса** - простой и понятный запуск и остановка.
- **Настраиваемая поддержка** - выбор интервала (в миллисекундах) между отправкой чисел.

## 🛠️ Требования

- **ОС:** Windows 10 / 11
- **Платформа:** NET 10.0
- **Среда разработки:** Visual Studio 2026

## 📖 Как пользоваться

1. Скомпилируйте и запустите программу. Сразу после открытия вам будет предложен список запущенных процессов, необходимо выбрать числовой идентификатор нужного окна.
2. Указать значение максимального числа, а также задержки (опять же в миллисекундах).
3. Использовать `ESC` для переключения режима работы.
